Linear Independence Practice With a Worked Proof

Work through a common first-year linear algebra mistake. Every vector can be nonzero even when the set is dependent.

Set up the proof by hand

Let v₁ = (1, 0, 1), v₂ = (0, 1, 1), and v₃ = (1, 1, 2). Are the three vectors linearly independent? Show what happens when you set av₁ + bv₂ + cv₃ equal to the zero vector.

  1. Write one equation for each coordinate.
  2. Use the first two equations to express a and b in terms of c.
  3. Substitute those expressions into the third equation. Does it force c to be zero?
Get one hint

The first two coordinate equations are a + c = 0 and b + c = 0. Write down what the third equation becomes once you substitute a = −c and b = −c.

Check the step that proves it

Show the worked answer

The third equation is a + b + 2c = 0. After substitution it becomes −c − c + 2c = 0 for every c. Choose c = 1, which gives a = b = −1. The coefficients (−1, −1, 1) are nonzero as a tuple and satisfy −v₁ − v₂ + v₃ = 0, proving dependence.

In geometric terms, v₃ = v₁ + v₂, so all three vectors lie in the plane spanned by v₁ and v₂.

Retry. Replace v₃ with (1, 1, 3). Keep your first two equations and change just the third. Can c still be any number?

Check the retry

The new third equation becomes −c − c + 3c = 0, so c = 0, then a = b = 0. The zero solution is now the only one, which proves independence.
